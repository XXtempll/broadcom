🚀 Void Linux Setup: Lenovo G510 (i7-4712mq / 16GB RAM)
Полный гайд по установке и автоматической настройке системы Void Linux Base с минималистичным оконным менеджером vxwm, инструментами для Web-разработки и оптимизацией под Dota 2.

💻 Спецификации целевого устройства
Модель: Lenovo G510

Процессор: Intel Core i7-4712mq (4 ядра, 8 потоков)

ОЗУ: 16 GB DDR3L

Графика: Intel HD Graphics 4600 (Mesa/Vulkan)

Сеть: Broadcom BCM43xx (требует broadcom-wl)

🛠 Часть 1: Установка Void Linux (Base)
Запись образа: Скачай void-live-x86_64-202XXXXX.iso (Base) и запиши на флешку через Rufus (режим DD) или Ventoy.

Загрузка: Вставь флешку, при включении нажимай F12 и выбери USB-накопитель.

Интернет: Подключи телефон к ноутбуку через USB-кабель и включи "USB-модем".

Запуск установщика:

Bash
sudo void-installer
Настройки в установщике:

Keyboard: ru или us.

Network: Выбери интерфейс модема (обычно enp0s20u...), нажми DHCP.

Source: Local (установка с флешки).

Hostname: void-g510.

Partitioning: Выбери cfdisk. Создай таблицу DOS (для BIOS) или GPT (для UEFI).

Раздел 1: Весь объем, тип Linux.

Filesystems: Для / выбери ext4. Назначь точку монтирования /.

Root Password: Введи пароль администратора.

User: Создай своего пользователя, добавь его в группы wheel, audio, video, optical, storage.

Bootloader: Обязательно "Yes" на установку в основной диск.

Завершение: После надписи "Success" введи reboot.

📦 Часть 2: Автоматическая настройка
После первой загрузки залогинься и убедись, что телефон всё еще подключен в режиме модема.

1. Подготовка
Bash
sudo xbps-install -Sy git
git clone https://github.com/твой_ник/твой_репозиторий
cd твой_репозиторий
chmod +x install.sh
2. Запуск скрипта
Скрипт установит драйверы Wi-Fi, DNS 8.8.8.8, графику, vxwm, VS Code и Steam.

Bash
sudo ./install.sh
🔧 Часть 3: Что делает скрипт (install.sh)
Ядро и Драйверы: Ставит linux-headers и broadcom-wl-dkms. Блокирует стандартные драйверы Broadcom, которые не работают.

DNS: Намертво прописывает 8.8.8.8 в /etc/resolv.conf и блокирует файл от изменений.

NetworkManager: Настраивает сеть для удобного управления через nmtui.

vxwm: Клонирует vxwm с Codeberg, компилирует и настраивает автозапуск через .xinitrc.

Web-Dev: Ставит Node.js LTS, VS Code и Python.

Dota 2: Устанавливает Steam и все необходимые 32-битные библиотеки и Vulkan-драйверы для Intel HD 4600.

⌨️ Часть 4: После установки
Как включить Wi-Fi?
После перезагрузки введи в терминале:

Bash
nmtui
Выбери "Activate a connection", найди свою сеть и введи пароль. Если список пуст, подожди минуту (драйвер Broadcom собирается в фоне при первом запуске).

Как запустить графику?
Bash
startx
Горячие клавиши vxwm
Mod (Win) + Enter — Открыть терминал (xterm).

Mod + p — Меню запуска приложений (dmenu). Вводи code для VS Code или steam для игр.

Mod + [1-9] — Переключение рабочих столов.

Mod + Shift + q — Выход из системы.

Оптимизация Dota 2
Для максимального FPS на i7-4712mq:

Запусти Steam.

В свойствах Dota 2 (Параметры запуска) напиши: -vulkan -high.

В самой игре выстави настройки на "Скорость".

⚠️ Устранение проблем
DNS не меняется: Если нужно сменить DNS, сначала сними блокировку: sudo chattr -i /etc/resolv.conf.

Нет звука: Выполни alsamixer, нажми F6, выбери свою карту и убедись, что каналы не на MM (Mute).

Wi-Fi всё еще не работает: Проверь загружен ли драйвер: lsmod | grep wl. Если нет, выполни sudo modprobe wl.
