# Void Linux Wi-Fi Installer (Broadcom)

Этот скрипт автоматизирует настройку Wi-Fi адаптеров Broadcom (драйвер `wl`) в **Void Linux**. Он также устанавливает NetworkManager и настраивает статический DNS от Google.

> **Важно:** Скрипт предназначен для ноутбуков (например, линейки Lenovo), где стандартные драйверы конфликтуют с оборудованием.

## Что делает скрипт:
1. Подключает репозиторий `non-free` и обновляет систему.
2. Устанавливает DKMS и драйвер `broadcom-wl-dkms`.
3. Вносит конфликтующие модули (`b43`, `bcma` и др.) в черный список.
4. Устанавливает **NetworkManager**.
5. Настраивает Google DNS (8.8.8.8) и защищает файл `resolv.conf` от перезаписи.
6. Включает необходимые системные службы (`dbus`, `NetworkManager`).

## Использование

### 1. Подготовка
Убедитесь, что у вас есть временное интернет-соединение (например, через Ethernet или USB-модем телефона), чтобы скрипт мог скачать пакеты.

### 2. Запуск
Установка только для **VoidOS**:

1. Установка Git
```bash
sudo xbps-install -S git
```
2. Клонирование репозитория 
```bash
sudo clone https://github.com/XXtempll/voidOS-broadcom-driver
```
3. Заходим в папку
```bash
cd voidOS-broadcom-driver
```
4. Запускаем установку
```bash
sudo bash install.sh
```
### 3. Завершение
После выполнения скрипта:
1. **Перезагрузитесь**: `sudo reboot`.
2. После входа в систему используйте консольный интерфейс для подключения к сети:
   ```bash
   nmtui
   ```
3. Если список сетей пуст, попробуйте принудительно загрузить модуль:
   ```bash
   sudo modprobe wl
   ```

## Примечание по DNS
Скрипт использует команду `chattr +i` для файла `/etc/resolv.conf`. Это значит, что система или роутер не смогут изменить ваши настройки DNS. Если вам понадобится изменить их вручную, сначала выполните:
```bash
sudo chattr -i /etc/resolv.conf
```
